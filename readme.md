# CodeMaster – Frontend Learning Landing Page

##  Project Overview

CodeMaster is a simple frontend learning landing page designed for beginners who want to start their web development journey.

The website provides information about frontend development courses such as HTML, CSS, and Responsive Design.

##  Technologies Used

* HTML5
* CSS3
* Flexbox
* Responsive Design

##  Features

* Responsive navigation header
* Hero section with a call-to-action button
* Course cards for HTML, CSS, and Responsive Design
* About Us section
* Hover effects
* Clean and simple user interface
* Responsive layout for different screen sizes

##  Project Structure

```text
CodeMaster/
│
├── index.html
├── style.css
└── README.md
```

##  How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

##  Learning Outcomes

Through this project, I practiced creating webpage structures using HTML and styling them using CSS.

I also learned how to use Flexbox, spacing, hover effects, and responsive design techniques.
